# RAMZES TATTOO

Персональный сайт тату-мастера RAMZES, Новосибирск.

## Стек
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4

## Запуск локально
```bash
npm install
npm run dev
```

## Перед публикацией
1. Заменить блоки-заглушки в разделе портфолио реальными фотографиями работ RAMZES.
2. Проверить контакты и ссылку на карточку Яндекс Карт.
3. Подключить домен и аналитику.
